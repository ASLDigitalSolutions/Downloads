## How releases are tagged

Several products share this repository, so every release is tagged product-version — for example homedisks-v0.1.0. That keeps their tags from colliding.

For the same reason, do not link to /releases/latest. The latest release is whichever product published most recently, which may not be the one you mean. Always link a specific tag.
